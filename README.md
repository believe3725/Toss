# 토스증권 조회 전용 프록시 서버

가계부 앱(주식 탭)에서 토스증권 계좌의 보유 종목·평가금액·손익을 자동으로
불러오기 위한 작은 서버입니다. **조회(GET)만 하고, 매매 주문 기능은
코드에 아예 없습니다.**

## 왜 서버가 필요한가요?
- 토스증권 Open API 키(client_secret)는 브라우저 파일에 넣으면 누구나
  볼 수 있어서 안전하지 않습니다. 이 서버가 키를 대신 보관합니다.
- 토스증권 Open API는 **허용된 IP에서만** 호출이 가능합니다. 그래서
  "고정 IP를 가진 서버"가 꼭 필요합니다. (Cloudflare Workers 같은
  서버리스는 대부분 고정 아웃바운드 IP를 주지 않아 이 용도엔 맞지 않습니다.)

## 준비물
1. 토스증권 계좌 (앱/PC 웹에서 바로 개설 가능)
2. 고정 공인 IP를 주는 무료/저가 VM. 추천: **Oracle Cloud "Always Free" VM**
   (평생 무료, 고정 공인 IPv4 제공) 또는 저가 VPS(월 몇천 원대) 아무거나
3. Node.js 18 이상이 설치된 서버 환경

## 배포 순서
1. **VM 준비**: Oracle Cloud(또는 다른 VPS)에서 무료 인스턴스를 만들고
   공인 IP를 확인합니다. (`curl ifconfig.me`로 서버 안에서 확인 가능)
2. **토스증권 API 키 발급**: 토스증권 PC 웹(WTS) 로그인 → 설정 → Open API
   메뉴에서 client_id / client_secret 발급. 같은 화면의 "허용 IP" 항목에
   1단계에서 확인한 서버의 공인 IP를 등록합니다.
3. **이 폴더를 서버에 업로드**: `scp`나 `git`으로 `toss-proxy` 폴더 전체를
   서버로 복사합니다.
4. **환경변수 설정**: 서버에서 `.env.example`을 `.env`로 복사한 뒤,
   client_id/secret과 APP_TOKEN(임의의 긴 문자열)을 채웁니다.
5. **정확한 API 경로 확인**: developers.tossinvest.com 공식 문서에
   로그인해서 토큰 발급 엔드포인트와 잔고 조회 엔드포인트의 정확한
   경로·응답 형식을 확인하고, `server.js` 상단의 URL 기본값이나 `.env`의
   `TOSS_TOKEN_URL` / `TOSS_HOLDINGS_URL`을 맞춰줍니다. (제가 넣어둔 값은
   검색으로 확인한 추정치라 실제 문서와 다를 수 있습니다.)
6. **실행**:
   ```bash
   npm install
   npm start
   ```
   `http://<서버 공인 IP>:3000/health` 로 접속해 `{"ok":true}` 가 뜨면
   정상입니다.
7. **(권장) HTTPS 적용**: 가계부.html을 `https://`로 열 경우, 브라우저가
   `http://`인 이 서버로의 요청을 막을 수 있습니다. Caddy나 nginx +
   Let's Encrypt로 이 서버 앞에 간단히 HTTPS를 씌우는 걸 권장합니다.
8. **가계부 앱에 연결**: 가계부.html의 "투자 > 계좌 연동" 카드에서
   - 프록시 서버 주소: `https://<서버 주소 또는 IP>:3000`
   - 앱 토큰: 4단계에서 정한 APP_TOKEN
   을 입력하고 저장하면 "잔고 불러오기" 버튼으로 동기화할 수 있습니다.

## 보안 체크리스트
- [ ] `.env` 파일을 깃 저장소에 올리지 않았는가 (`.gitignore`에 포함됨)
- [ ] APP_TOKEN을 충분히 길고 예측 불가능하게 정했는가
- [ ] 허용 IP를 이 서버의 IP로만 좁혀놨는가
- [ ] 이 코드에 주문(order) 관련 엔드포인트를 추가하지 않았는가
